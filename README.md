# M-Vsynth2

**Synth2, the open-source recreation of Synth1, on the M-VAVE FM-1.**

M-Vsynth2 is open-source firmware for the M-VAVE FM-1. It is the FM-1 edition of
[Synth2](https://github.com/chab/oxo_synth2), François Chabloz's recreation of **Synth1** (the freeware synthesizer by
Daichi Laboratory): its floating-point engine rewritten in C99 fixed point for the FM-1's chip (no FPU), with every
law taken from Synth2's measurements of the original's sound. It plays Synth1's `.sy1` patches: the same 99
parameters, the same values, in and out.

> **Status: complete and tested on the FM-1.** The engine (stages 4a to 4e of the
> [port proposal](docs/design/mvsynth2-port-proposal-2026-11-13.md)) plays every Synth1 parameter and is checked
> against Synth2's own engine in 379 cases, every factory patch among them (`tests/run_compare.sh`). The panel, the
> banks and the patch transfer (stages 5, 6) are in, and all of it has been checked on the FM-1 itself.

## This build

```sh
sh tests/run_unit.sh                              # the tables, the patch, the .sy1 tool, the engine's plumbing
sh tests/run_compare.sh                           # the engine against Synth2's own, case by case (needs g++, numpy)
tests/run_host.sh tests/scripts/play.txt          # on your computer: build/host/mvsynth2.wav and the screens
./build.sh                                        # build/mvsynth2.fwsc
python3 tools/fm1_install.py build/mvsynth2.fwsc  # or .\flash.ps1 on Windows
```

On the FM-1: the keys play; PRESETS picks the program; the section buttons open the pages (below); HOME's four knobs
are the patch's own (GLO's HOME KNOBS page; FREQ, RES, AMOUNT and GAIN unless set). HOME shows the patch, a scope of what plays, and what it costs (CPU, PEAK); every screen shows the voices sounding
(the eight cells at the top right).
MIDI in plays it too (notes, bend, the sustain pedal, program change, bank select, clock, and a CC for every knob).

## The synth

| | |
| --- | --- |
| **Voices** | 8, rendered on both of the chip's cores (every other sounding voice on the second; HOME's foot shows **2CPU**; a unit whose second core fails falls back to one, as Melodee does). POLY, MONO, LEGATO; PORTAMENTO with AUTO; UNISON of 2 to 8 voices with DETUNE, SPREAD, PITCH and PHASE. A VOICES limit (GLOBAL). |
| **OSC 1** | SINE, SAW, PULSE, TRIANGLE. DETUNE (eight copies around the note), FM from OSC 2, PHASE. |
| **SUB** | SINE, TRIANGLE, SAW, SQUARE, at the note or an octave down, locked to OSC 1. |
| **OSC 2** | SAW, PULSE, TRIANGLE, NOISE. PITCH ±60 semitones, FINE, keyboard TRACK on or off, SYNC to OSC 1, RING. |
| **Common** | MIX, P/W, KEY SHIFT, TUNE. MOD ENV (attack, decay, amount) to OSC 2 pitch, FM or P/W. |
| **Filter** | LP12, LP24, HP12, BP12, LPDL, and SH101 (M-Vsynth2's own: the SH-101's VCF, see docs/SH101_FILTER.md). FREQ, RES, envelope AMOUNT, KBD TRACK, SATURATION, velocity switch. FILTER ENV (ADSR). |
| **Amp** | AMP ENV (ADSR), GAIN, velocity sensitivity, PAN. |
| **LFOs** | Two: saw, triangle, square, S&H, smooth random, sine. To OSC 2, OSC 1+2, filter, amp, P/W, FM or pan. TEMPO sync, KEY sync. |
| **Effects** | EFFECT (two analog distortions, digital distortion, decimator, ring modulator, compressor, four phasers), EQ (tone and a peak), DELAY (stereo, cross, ping-pong; tempo times, spread, tone), CHORUS (four types). A limiter on the output. |
| **Arpeggiator** | Synth1's: UP&DOWN, UP, DOWN, RANDOM; 1 to 4 octaves; BEAT; GATE. Its own tempo, or MIDI clock. |
| **Programs** | Banks of 128, as Synth1 has them: FACTORY (read-only) and U1 to U8 in flash, 1024 patches of your own. SAVE writes into any slot of U1..U8; the computer page sends, reads, clears. The name in the warning colour (orange on most themes): edited, not saved. |
| **MIDI** | USB-MIDI in and out, the TRS MIDI IN. Notes (a channel or any), program change, bank select, pitch bend, the patch's two controller routes (any CC, the bend, channel pressure), the sustain pedal, clock (the tempo). Every knob receives a CC of its own. |

Integers only: the chip has no FPU. Tables are generated by `tools/gen_tables.py`, `gen_wave.py` and `gen_params.py`
from Synth2's sources and committed.

**Not as Synth2** (the chip's limits): 8 voices, not 32; one oscillator table per 6 semitones, not per note; the
cutoff moves every 16 samples (ramped between), and so do the arp's steps; delay times up to 1 s; delay and chorus lines
of 16 bits. LFOs, the mod env, pitch, P/W and FM move every sample, as in Synth2. The engine's header
(`firmware/src/vs_voice.h`, "Not as Synth2") has the list, and the compare tool shows each.

## The panel

Synth1's sections are pages on the FM-1's screen. A section button opens its first page, again the next (it loops);
KNOB 1–4 edit the four columns, left to right; SELECT steps the knob touched last; ALGORITHM walks every page;
PRESETS picks the program; HOME goes home. On HOME the four knobs are the patch's HOME KNOBS (GLO, below), over a voice
strip, CPU, the tempo and the octave.

| Button | Pages |
| --- | --- |
| **LFO** | LFO 1 (2 pages), LFO 2 (2 pages) |
| **EDIT** | OSC 1, SUB OSC, OSC 2, OSC MIX, OSC COMMON |
| **ENV** | MOD ENV, FILTER ENV, AMP ENV |
| **SEL** | FILTER (2 pages), AMP |
| **FX** | FX SWITCH (EFFECT, DELAY, CHORUS on / off), EFFECT, EQ, DELAY (2 pages), CHORUS (2 pages) |
| **GLO** | VOICE, UNISON (2 pages), CONTROL (2 pages), HOME KNOBS (which parameter each of HOME's four knobs turns: kept with the patch, so SAVE keeps it; a `.sy1`, or a patch sent without them, gets FREQ, RES, AMOUNT, GAIN), GLOBAL 1/3 (MIDI CH, VOICES, TEMPO; CLOCK reads INT or EXT), GLOBAL 2/3 (THEME, COLOUR), GLOBAL 3/3 (DIAG) |
| **ARP** | tap: the arp on / off; hold 0.4 s: ARP |
| **SEQ** | BANK: KNOB 1 the bank (FACTORY, U1 .. U8), SELECT or PRESETS its 128 slots; the patch under the cursor plays |
| **SAVE** | its screen: KNOB 1 the bank (U1 .. U8), KNOB 2 the slot (it shows what is there, in any bank: REPLACES and its name, or EMPTY SLOT), KNOB 3 the cursor in the name and KNOB 4 (or SELECT) the character under it; SAVE again writes, any other button leaves. The bank goes to flash once nothing sounds |
| **OCT- OCT+** | the octave; both held 1 s: all notes off |

Every knob, range and choice: the cheat sheet (`docs/cheatsheet.html`), generated from the firmware's own page table.

**The screen** (`firmware/src/vs_ui.c`; [the design](docs/design/mvsynth2-ui-2026-11-14.md)). Every page is the same
four bands: the section and the page's title (a pip a page of the section, a cell a voice); a graph of what the page
does, drawn from the patch (the filter's response, the envelope's shape, the wave, the LFO with its running phase, the
echoes, the signal path...); the four knobs, in the order of KNOB 1..4; the program at the foot. A knob shows its kind:
an arc from the start (a value), from the top (a signed value), a segment a choice, or a switch. The knob in hand turns
to the accent colour for 1.5 s, with its value large on the graph. FREQ's thin outer arc is the span the filter
envelope adds. Six themes (SEA, EMBER, ICE, ORCHID, CRT, PAPER) on GLOBAL 2/3; COLOUR PATCH takes each patch's `.sy1`
colour as the theme's own.

## Patches to and from a computer

**The patch library, `docs/library.html`** (Chrome or Edge, Web MIDI; one self-contained page, nothing loaded from
anywhere, so it works hosted or opened from disk). What you have opened sits above, the FM-1's banks below, each bank
shown whole with every name in full:

- **Open** `.sy1` files, a folder (a Synth1 bank folder), a zip bank, or an exported library; drop them on the page
  too. The Synth2 Factory bank is built in. What you open is kept in this browser.
- **Find**: search names and tags (`cat:pad tag:warm colour:blue src:factory bank:u1 dup`), or click a category.
- **Drag** one patch or many onto a slot: they fill from there (**Empty slots only** skips filled ones). Drag inside a
  bank to move, Alt to copy; drag up to keep device patches in the library. `S` sends the selection to the slot in
  focus; `Del` clears; `Ctrl+Z` undoes.
- **Send** writes only what changed, each write acknowledged and read back; **Restore** puts a bank back as it was
  before the session's first send. **Read**, **Download** (a zip of `NNN.sy1`: a Synth1 bank folder as it stands, which
  opens in Synth2 and in Synth1), **Export library** (your sources, categories and tags).
- **Audition** (double-click or `Enter`) plays a patch on the FM-1 without saving it. **Patch details** (`I`): rename,
  colour, category, tags, the filter and amp envelope drawn.
- **Sandbox**: a pretend FM-1 inside the page, to try all of it with nothing plugged in.
- The six themes of the FM-1's screen. The page refuses an FM-1 running another firmware.

Old `.sy1` versions are converted on the way in, exactly as Synth2 converts them. USB only. The page is built by
`tools/gen_library_page.py` from fm1-kit's library (`third_party/fm1-kit/`, shared with the other FM-1 firmwares) and
M-Vsynth2's adapter (`library/`). `docs/bank.html`, the old bank page, now opens it.

From a terminal (`pip install mido python-rtmidi`): `python3 tools/sy1_xfer.py send FOLDER --bank 2`, `read --bank 2 OUT/`,
`play FILE.sy1`, `select 2 12`, `clear --bank 2 12`, `ident`.
The protocol: `firmware/src/vs_xfer.h`.

The factory bank is a folder, `tools/bank/factory/`: `python3 tools/make_bank.py` turns its `.sy1` files into
`firmware/gen/vs_factory.h`; rebuild the firmware after.

## Screen reader

M-Vsynth2 speaks its screen through [fm1-reader](https://github.com/charlesvestal/fm1-reader) by Charles Vestal (issue
#1): plug the FM-1 in over USB and open the reader's page in Chrome or Edge. The page speaks with its own voice, or hands
the words to VoiceOver, NVDA, JAWS or TalkBack. The FM-1 sends text and the page does the speaking, so nothing has to
be installed on the computer.

- **When the reader connects**, and on its WHERE, the whole screen: the page and its four knobs with their values, and
  the patch.
- **A new page or screen**, once page flipping settles: its name (FILTER PAGE 1 OF 2), then its knobs.
- **A knob turning**: its name and value (FREQUENCY 64) once it settles, and at least every half second while it turns.
  A CONTROL route says where it goes (ASSIGN 1 TO LFO 1 DEPTH).
- **PRESETS, a program change, a bank**: the bank, slot and name. **SEQ**: the slot under the cursor and its place
  (PAD PWM RAW, 3 OF 128).
- **SAVE**: where it writes and what it replaces; KNOB 3 says the cursor and its character, KNOB 4 the character
  (CAPITAL B, SMALL B, SPACE, DASH); the write says SAVED, or NOT SAVED as a warning.
- **OCT- / OCT+** (OCTAVE UP 1), **all notes off**, the **HOME KNOBS** choices and **GLOBAL** pages.

Nothing is sent until a reader says hello, so a DAW on the same port never sees a byte. The screen's short labels are
said in full by the words file, `firmware/words.tsv` -> `docs/words/<id>.json` (published with the site; the device
sends its link). After changing a label, run `python3 tools/gen_words.py firmware/words.tsv docs/words firmware/gen/ann_words.h`
(tests/run_unit.sh does) and commit both. `sh tests/run_speak.sh` checks a session and audits every message with
fm1-reader's `tools/audit.mjs` (clone fm1-reader next to this repository). The firmware side is `firmware/src/vs_speak.c`.

## Install

**From the browser: the firmware page, `docs/flash/`** (the site's *Install the firmware*; Chrome or Edge on a
computer). Find the FM-1, take the latest release (or a `.fwsc` from your computer), tick the box, Install. It is the
same update as `tools/fm1_install.py` (fm1-kit's `web/fm1ota.js`): the package is checked first (identity, the update
loader, every file's CRC; a release's SHA-256 too), a package for another model is refused, and the FM-1's own update
loader stays until the write is done, so a cut-off install is finished by running it again. On Windows close the
patch library and any DAW first: only one program can use the FM-1's MIDI port.

Otherwise: the FM-1 Firmware Hub once listed, or `python3 tools/fm1_install.py mvsynth2-X.Y.fwsc`. If it won't
start, hold **OCT-** while switching on: the USB rescue.

**The site** (GitHub Pages, `.github/workflows/pages.yml`): the front page, the firmware page, the patch library, the
simulator, the cheat sheet. A release (`release.yml`, on a tag `vX.Y`) starts the Pages workflow, which puts that
release's packages and `firmware/latest.json` (`tools/flash_manifest.py`) beside the firmware page.

**Traffic.** Page views and installs are counted with [GoatCounter](https://www.goatcounter.com) (open source, no
cookies, nothing personal kept) at <https://bk40.goatcounter.com>, shared with M-vance's site (told apart by path; the
repo variable `GOATCOUNTER_URL` points this site elsewhere). Local copies never count. Besides views, the firmware page
sends `M-Vsynth2/flash/start/<identity>`, `.../done/<identity>` and `.../fail/<reason>`: the dashboard's events show
installs and failures by version.
GitHub's own figures are under *Insights > Traffic* (14 days) and each release's download counts.

## Build and run

M-Vsynth2 is built on [Dinghy](https://github.com/zvenson/dinghy) as [M-vance](https://github.com/bk40-home/M-vance)
carries it, and keeps its platform unchanged. The toolchain and SDK are M-vance's (its README, "Build and run").

```sh
git submodule update --init third_party/oxo_synth2   # Synth2: read by the generators and compare tools only
sh tests/run_unit.sh                        # the engine's unit tests
tests/run_host.sh [script]                  # the firmware on your computer: sound as a WAV, the screens as PNGs
sh tests/run_compare.sh                     # each fixed-point part beside Synth2's float one
sh tests/run_docs.sh                        # the cheat sheet and the web page's screens, from the firmware
./build.sh                                  # build/mvsynth2.fwsc
python3 tools/fm1_install.py build/mvsynth2.fwsc
```

On Windows, `.\flash.ps1` does the same through WSL.

### Build settings

Set at build time, with no code to edit: `.\flash.ps1 -Defs "-DNAME=value"` on Windows, or
`DINGHY_DEFS="-DNAME=value" ./build.sh`. Several go in one string, separated by spaces. The next build without them is the
normal firmware again.

| Setting | Default | What it does |
| --- | --- | --- |
| `SH101_SING_TRIM` | `0.7f` | FILTER TYPE 5 (SH101): its level when it self-oscillates. `1.0f` is the real circuit (+5.6 dB over a full oscillator: right for a mono synth, but 3-4 notes singing run into the output limiter). Lower it for big resonant chords (`0.4f` is -8 dB), raise it for solo lines. It eases in above the onset, so it changes nothing below RES ~108 |
| `SH101_RES_TAPER` | `2.0f` | Type 5's RES knob curve: `1.0f` is the 101's linear slider (it sings from RES 92); `2.0f` sings from ~108, more of the knob below |
| `SH101_RES_MAX` | `10.0f` | Type 5's RES at knob 127, on the 101's 0..10 scale; below `7.2f` it never self-oscillates |
| `SH101_CUT_MIN_HZ`, `SH101_CUT_MAX_HZ` | `7.0f`, `11550.0f` | Type 5's FREQ range |
| `VS_SH101` | `1` | `0`: no type 5 (it plays as LP24), no float code |
| `VS_LPDL` | `1` | `0`: no LPDL (type 4 plays as LP12) |
| `VS_NV` | `8u` | Voices |

Example: `.\flash.ps1 -Defs "-DSH101_SING_TRIM=0.85f -DSH101_RES_TAPER=1.5f"`. More on type 5: [docs/SH101_FILTER.md](docs/SH101_FILTER.md).

The chip's rules: [docs/RULES.md](docs/RULES.md); the platform's calls: [docs/API.md](docs/API.md).
